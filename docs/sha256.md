## SHA-256 Explanation

This is a simple explanation of the SHA-256 hashing algorithm, which is used in this project.

Basic knowledge of computer architecture / binary is required. Try [Turing Complete](https://turingcomplete.game/), it's a great way to learn!

I also recommend reading this, for better understanding: [FIPS PUB 180-4 (NIST official spec)](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf)

---

### 1. Input Conversion to Bytes

All input strings are converted to bytes using UTF-8. This gives a raw byte representation of the input.

```python
b"hello" → [0x68, 0x65, 0x6c, 0x6c, 0x6f]
```

### 2. Message Padding

SHA-256 requires the message length to be a multiple of 512 bits (64 bytes).
Therefore, we need to pad the input message:

* Append a single `1` bit → (in hex: `0x80`)
* Append `0` bits until the length is 64 bits short of a multiple of 512
* Append the original message length as a 64-bit big-endian integer


### 3. Splitting into 512-bit Chunks

The padded message is split into 64-byte (512-bit) blocks. Each block is processed.


### 4. Preparing the Message Schedule

Each block is turned into 64 32-bit words `w[0..63]`:

* The first 16 words come directly from the block
* The remaining 48 are computed using:

```
s0 = (w[i-15] >>> 7) ^ (w[i-15] >>> 18) ^ (w[i-15] >> 3)
s1 = (w[i-2] >>> 17) ^ (w[i-2] >>> 19) ^ (w[i-2] >> 10)
w[i] = w[i-16] + s0 + w[i-7] + s1
```

All operations are mod 2³².


### 5. Initialize Hash Values

There are 8 initial 32-bit words (constant)

```
h0 = 0x6a09e667
h1 = 0xbb67ae85
...
h7 = 0x5be0cd19
```


### 6. Compression Function

To make all inputs end up with the same length, a compression function is used.
This runs 64 rounds.

Each round updates 8 variables `a` to `h`:

A single round looks like this:

```
S1  = (e >>> 6) ^ (e >>> 11) ^ (e >>> 25)
ch  = (e & f) ^ ((~e) & g)
temp1 = h + S1 + ch + k[i] + w[i]

S0  = (a >>> 2) ^ (a >>> 13) ^ (a >>> 22)
maj = (a & b) ^ (a & c) ^ (b & c)
temp2 = S0 + maj

# Rotate registers
h = g
g = f
f = e
e = d + temp1
d = c
c = b
b = a
a = temp1 + temp2
```

Mod 2³² again.


### 7. Add This Chunk's Hash to Result

The compressed values are added to the current hash values:

```python
h0 = (h0 + a) % 2**32
h1 = (h1 + b) % 2**32
...
h7 = (h7 + h) % 2**32
```

### 8. Final Output

The final hash is the concatenation of the 8 hash values:

```python
return h0 || h1 || h2 || ... || h7
```

The final has is always 256 bits (32 bytes) long.

Hex: `a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e` (Hello World)
